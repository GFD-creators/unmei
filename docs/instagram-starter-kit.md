# 運命図鑑ウンメイ ｜ Instagram スターターキット（土台＆サンプル投稿）

アカウント開設直後にそのまま使える「土台一式」と、すぐ投稿できる「サンプル投稿5本（画像＋文章＋ハッシュタグ）」。
戦略の全体像は [`instagram-strategy.md`](./instagram-strategy.md)、広告は [`instagram-ad-plan.md`](./instagram-ad-plan.md) を参照。

- 投稿画像: `assets/posts/`（`.jpg` を入稿に使う。再生成は `python make_ig_posts.py`）
- LP: https://gfd-creators.github.io/unmei/

### A-3. プロフィール画像
`assets/chars/rare_legendary_angelpoodle.png`（天使プードル）の顔まわりを正方形にトリミング。丸アイコンでも顔が見えるよう中央寄せ。

### A-4. ハイライト（開設後すぐ4つ）
| ハイライト名 | 中身 |
|---|---|
| 診断してみた | 自分/フォロワーの診断結果スクショ |
| レアキャラ | 4体のレア紹介・出た報告 |
| 相性 | 相性診断の使い方・結果例 |
| つかいかた | 生年月日を入れるだけ、の3ステップ説明 |

### A-5. link in bio（リンク集＋UTM）
`lit.link` / `Linktree` などでリンク集を作り、各リンクにUTMを付ける（流入元が分析できる）。
すべて `utm_source=instagram&utm_medium=social` を基本に、`utm_content` で出し分け:

```
無料で診断する →  https://gfd-creators.github.io/unmei/?utm_source=instagram&utm_medium=social&utm_campaign=bio&utm_content=diagnose
相性をチェック →  https://gfd-creators.github.io/unmei/?utm_source=instagram&utm_medium=social&utm_campaign=bio&utm_content=aisho
全国ランキング →  https://gfd-creators.github.io/unmei/?utm_source=instagram&utm_medium=social&utm_campaign=bio&utm_content=ranking
```

> ストーリーズのリンクスタンプは `utm_content=story_YYYYMMDD` のように日付で分けると、どのストーリーが効いたか分かる。

## C. 投稿運用のコツ（この5本の回し方）

- **順番**: ①（固定）→ ③干支×MBTI → ⑤相性 → ②あるある（カルーセル）→ ④レア、のように「診断紹介 → 参加型 → シェア型」を交互に。
- **頻度**: フィードはこの5本を土台に、慣れたらリールへ横展開（画像＋流行り音源＋字幕）。ストーリーズは毎日、投票/質問/リンクで軽く。
- **時間帯**: 放課後〜夜（17–22時）・土日を厚めに。
- **ハッシュタグ**: 8〜15個。大（#MBTI）中（#MBTI診断）小（#運命図鑑ウンメイ）を混ぜる。毎回まったく同じ羅列は避け、投稿内容に合わせて2〜3個入れ替える。
- **CTAの型**: フィードは必ず「プロフィールのリンクから」を添える（本文にリンクは貼れないため）。参加を促す一言（コメント/保存/シェア/タグ付け）も毎回入れる。
- **表現の注意**: 「あなたは〜だ」と断定せず「〜かも？」「診断してみて」の問いかけ形に（広告に転用する際のMetaポリシー対策にもなる）。
