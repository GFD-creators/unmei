# 運命図鑑ウンメイ ｜ Instagram 広告 出稿プラン

Instagram（Meta）広告を出すための準備一式。**画像クリエイティブ・計測タグ・配信設計・広告コピー・運用チェックリスト**をまとめる。

- 遷移先（LP）: https://gfd-creators.github.io/unmei/
- 目的: サイトへの流入 → 診断完了（`result_view`）→ シェア／収益クリックの拡大
- 課金モデル: 無料の診断コンテンツ（アプリインストールではなく **Web誘導**）

---

## 0. まず最初にやること（30分）

1. **Metaビジネススイート / 広告アカウント**を用意（未作成なら [business.facebook.com](https://business.facebook.com/) から）
2. **Instagramアカウント**を広告アカウントに連携（プロアカウント推奨）
3. **Metaピクセルを1つ作成**し、IDを控える（イベントマネージャ → データソース → ピクセル）
4. `index.html` の `YOUR_META_PIXEL_ID`（**2か所**）を、そのIDに置換 → デプロイ
5. Metaの **イベントテストツール**で `PageView` と `ViewContent` が飛ぶか確認
6. 支払い方法を登録

これで計測が回り始める。以降はクリエイティブと配信設定。

---

## 1. 計測セットアップ（実装済み ✅ ／ 手順）

### 1-1. Meta ピクセル（実装済み）
`index.html` の `<head>` にピクセルを設置済み。**ピクセルIDが未設定（プレースホルダ）のあいだは一切発火せず、エラーも出ない**ので安全にデプロイできる。IDを入れた瞬間に有効化される。

- 設置場所: `index.html` 内 `<!-- Meta (Facebook / Instagram) Pixel -->`
- 差し替える箇所: `window.META_PIXEL_ID = 'YOUR_META_PIXEL_ID';` と `<noscript>` の `id=YOUR_META_PIXEL_ID`（**計2か所**）
- CSP（Content-Security-Policy）も `connect.facebook.net`（スクリプト）と `www.facebook.com`（送信先）を許可済み

### 1-2. 既存イベント → Meta へ自動転送（実装済み）
サイト内の計測は `window.ev(name, params)` に集約されている。ピクセル設置スクリプトがこれを**ラップ**し、GA4送信はそのままに、**全カスタムイベントをMetaにも自動送信**する。主要地点はMeta標準イベントにもマップ済み:

| サイト内イベント | 意味 | Meta標準イベント | 最適化での使いどころ |
|---|---|---|---|
| `result_view` | 診断結果を表示（＝主要CV） | **ViewContent** | コンバージョン最適化のイベントに指定 |
| `monetize_click` | 収益リンククリック | **Lead** | 収益に近い上位イベント |
| `quiz_start` | 診断スタート | （カスタム） | 上位ファネル計測 |
| `quiz_complete` | 診断完了 | （カスタム） | 完了率の把握 |
| `share_attempt` / `invite_share` | シェア | （カスタム`Share`） | 拡散の把握 |
| `rare_summon` | レアキャラ出現 | （カスタム） | バズ要素の把握 |
| `compat_cta` / `compat_viewed` | 相性機能 | （カスタム） | 機能別の関心 |

> 追加のコード変更は不要。新しいイベントを増やしたい場合も `ev('名前', {パラメータ})` を呼ぶだけでGA4とMetaの両方へ届く。

### 1-3. カスタムコンバージョンの登録（Meta管理画面で）
イベントマネージャ → **カスタムコンバージョンを作成**:
- 「診断完了」= `ViewContent`（または `result_view`）→ **キャンペーンのコンバージョン目標に設定**
- 「収益クリック」= `Lead`（`monetize_click`）→ 上位ゴールとして別途登録

### 1-4. GA4 × UTM（追加実装不要）
GA4は `utm_source / utm_medium / utm_campaign / utm_content / utm_term` を**自動で計測**する（`page_view` に含まれる）。広告リンクにUTMを付ければ、GA4の「集客 → トラフィック獲得」で流入元別に分析できる。Metaピクセルは `fbclid` を自動処理する。

---

## 2. UTM 設計（広告リンクに付与）

命名を統一しておくと後で分析が楽。**すべて小文字・スネークケース**推奨。

```
https://gfd-creators.github.io/unmei/?utm_source=instagram&utm_medium=paid_social&utm_campaign=unmei_launch_2026q3&utm_content=01hook_4x5&utm_term=lookalike1
```

| パラメータ | 値の例 | 用途 |
|---|---|---|
| `utm_source` | `instagram` / `facebook` | 媒体 |
| `utm_medium` | `paid_social` | 有料ソーシャル |
| `utm_campaign` | `unmei_launch_2026q3` | キャンペーン単位 |
| `utm_content` | `01hook_4x5` / `02rare_9x16` | **クリエイティブ識別**（下の一覧のキー） |
| `utm_term` | `lookalike1` / `interest_uranai` | オーディエンス識別 |

> Metaの「URLパラメータ」欄に `utm_source=instagram&utm_medium=paid_social&utm_campaign=unmei_launch_2026q3` を入れ、`utm_content` は広告ごとに手動で分けると管理しやすい。

## 3. 画像クリエイティブ（12点・生成済み）

`assets/ads/` に **4コンセプト × 3サイズ** を PNG / JPG で出力済み。再生成は `python make_instagram_ads.py`。

| コンセプト | 狙い | ファイル接頭辞 |
|---|---|---|
| ① フック（運命キャラ） | 王道・最初に回す基準 | `ad_01_hook_*` |
| ② レア1% | 射幸性・ガチャ欲を刺激 | `ad_02_rare_*` |
| ③ 相性チェック | 恋愛・友達とシェア動機 | `ad_03_aisho_*` |
| ④ 全国ランキング | 自分の順位が気になる | `ad_04_ranking_*` |

サイズと配置の対応:

| サイズ | ファイル接尾辞 | 主な配置 |
|---|---|---|
| 1:1（1080×1080） | `_1x1` | フィード（Instagram/Facebook）・発見タブ |
| 4:5（1080×1350） | `_4x5` | **フィード推奨**（モバイル占有が最大） |
| 9:16（1080×1920） | `_9x16` | ストーリーズ・リール（UI安全域を確保済み） |

> **Advantage+ クリエイティブ**を使う場合、1点入稿すると自動でトリミングされるが、比率ごとに専用画像を入れたほうがCTRは安定する。まずは 4:5 と 9:16 を主軸に。

### A/Bテストの回し方
1. **第1週**: 4コンセプトの `4x5` を同一予算・同一オーディエンスで並走（クリエイティブテスト）
2. CTR / CPC が上位2コンセプトに絞る
3. 勝ちコンセプトで `9x16`（ストーリーズ/リール）も追加し配置を広げる
4. コピー（下記）を2〜3パターン差し替えてさらにテスト

## 4. 広告コピー案（プライマリテキスト・見出し・CTA）

Metaの入稿枠 = **プライマリテキスト（本文）／見出し／説明／CTAボタン**。コンセプト別に用意。絵文字は1〜2個まで。

### ① フック（運命キャラ）
- 本文A: `生まれた日から、あなただけの「運命キャラ」がわかる。MBTI×干支で全192タイプ✨ 30秒・無料で診断できます。`
- 本文B: `あなたはどの子？💗 生年月日を入れるだけで、運命のキャラと2026年の運勢がわかる無料診断。`
- 見出し: `無料で運命キャラ診断` / `あなたの運命キャラは？`
- 説明: `MBTI × 干支 = 192タイプ`
- CTA: **診断する（今すぐ試す）**

### ② レア1%
- 本文A: `出現確率わずか1%…🌟 あなたは「レアキャラ」を引けるか？生まれた日で決まる運命のガチャ、無料で挑戦。`
- 本文B: `隠れたレアキャラは全4体。あなたの生まれた日に眠ってるかも？💫 いま運試し。`
- 見出し: `レア出現率1%に挑戦` / `あなたはレアを引ける？`
- CTA: **今すぐ試す**

### ③ 相性チェック
- 本文A: `気になるあの人との相性、何点？💕 MBTI×干支×レアで100点満点採点。2人の生年月日だけでOK・無料。`
- 本文B: `友達と、恋人と。ふたりの相性を100点満点で診断🌈 スクショしてシェアしたくなる可愛さ。`
- 見出し: `ふたりの相性を100点採点` / `あの人との相性は何点？`
- CTA: **相性を見る**

### ④ 全国ランキング
- 本文A: `モテ・金運・メンタル…7つの運命ステータスで、あなたは全国何位？📊 800万人ランキングを無料でチェック。`
- 本文B: `あなたの“隠れステータス”は全国トップ？💪 生まれた日でわかる7軸ランキング診断。`
- 見出し: `全国ランキングで何位？` / `あなたの運命ステータス`
- CTA: **順位を見る**

> **表現の注意（重要）**: Metaは広告文で「**あなた**は〜だ」と個人属性（性格・健康・メンタル・経済状況など）を**断定・言い当てる**表現を禁止している。「あなたはモテません」等はNG。「あなたの◯◯がわかる」「診断してみよう」の**問いかけ・提案形**にとどめる。占い・診断系は景表法の観点でも「必ず当たる」等の断定を避ける。

## 5. ターゲティング

| 項目 | 推奨 |
|---|---|
| 地域 | 日本 |
| 年齢 | 13〜34（コア: 16〜24 の女性中心。可愛い系×占い×シェア文化と親和） |
| 性別 | 全性別で開始 → 実績で寄せる |
| 詳細ターゲット | 占い / 星座・占星術 / MBTI / 心理テスト / アニメ・キャラクター / サンリオ等の可愛い系ブランド / 恋愛・マッチング関心 |
| 配置 | まずは **Advantage+ 配置**（自動）。実績が溜まったら Instagram（フィード・ストーリーズ・リール・発見）に寄せる |
| オーディエンス拡張 | 学習が進んだら **類似オーディエンス（1%）** を `ViewContent` ベースで作成 |

> 初期は**興味関心を絞りすぎない**。Metaの最適化が効くよう、まずは広め＋Advantage+で回し、データが溜まってから類似・リタゲに投資する。

## 6. キャンペーン構成・予算

### 目的（Objective）
- 立ち上げ期: **トラフィック**（リンククリック / ランディングページビュー最適化）で安く流入を集めつつピクセルにデータを貯める
- データが溜まったら（`ViewContent` が週50件目安）: **売上／コンバージョン**目的に切替え、`ViewContent` を最適化イベントに

### 構成例（ABO）
```
キャンペーン: unmei_launch_2026q3
├─ 広告セットA: 興味関心(占い/MBTI)   日予算 ¥1,000
│   ├─ 広告 01hook_4x5
│   ├─ 広告 02rare_4x5
│   ├─ 広告 03aisho_4x5
│   └─ 広告 04ranking_4x5
└─ 広告セットB: Advantage+ オーディエンス 日予算 ¥1,000
    └─ 同上4クリエイティブ
```

- **少額テスト**（1日 ¥1,000〜2,000）で3〜5日 → 勝ちクリエイティブ/オーディエンスを見極め
- 勝ち筋が出たら **CBO（Advantage キャンペーン予算）** に寄せてスケール
- 1広告セットあたり **学習期間（約50CV/週）** を意識し、頻繁な編集を避ける

### 見るべき指標
| 指標 | 目安・見方 |
|---|---|
| CTR（リンク） | 1%未満ならクリエイティブ/コピーを見直し |
| CPC | 媒体・時期次第。相対比較で安い広告に寄せる |
| LPビュー率 | クリック→表示。低ければ表示速度/遷移先を確認 |
| `ViewContent`（診断完了）単価 | 主要KPI。ここを下げる方向で最適化 |
| シェア率 / `rare_summon` | バズ・二次拡散のポテンシャル |
