# 運命図鑑ウンメイ ｜ Instagram 運用マスタープラン

アカウント開設からターゲット・運用・広告・KPIまでの全体設計。
**広告の具体的な入稿手順・コピー・UTMは [`instagram-ad-plan.md`](./instagram-ad-plan.md) に分離**（本書はその上位の戦略）。

- 遷移先（LP）: https://gfd-creators.github.io/unmei/
- ゴール（KPI）: **収益最大化 = サイト流入 / PV の最大化**（AdSense＋A8アフィリ）
- リソース想定: **週ほぼ毎日投稿できる工数 ＋ 広告費 月数万円**
- 推奨スタイル: **オーガニック（リール主体）＋少額広告のハイブリッド**

---

## 0. 最初に押さえる「構造」— これが戦略の土台

> **Instagramのフィード投稿は、本文にクリックできるリンクを貼れない。**

収益ゴール（＝サイトに来てもらってナンボ）にとって、これは決定的。だから役割を分ける:

| 手段 | サイト送客力 | 本当の役割 |
|---|---|---|
| フィード投稿 | 弱い（リンク不可） | 保存・信頼・世界観づくり。プロフィールへ誘導 |
| リール | 中（リンク不可だがリーチ最大） | **新規リーチ / フォロワー獲得 / 認知**の主力 |
| ストーリーズ | 中（リンクスタンプで踏める） | 既存フォロワーを**その場でサイトへ**送る唯一の無料経路 |
| プロフィール(link in bio) | 中 | 全導線の受け皿。UTMで計測 |
| **有料広告** | **強（直リンク可）** | **実際にサイトへ送客して刈り取る本命** |

**結論:** オーガニックで「リーチ＝母集団」と「信頼＝ファン」を作り、**ストーリーズのリンク＋広告で刈り取る**。オーガニックは同時に、広告のリターゲティング母集団と勝ちクリエイティブの発掘装置にもなる。毎日投稿＋月数万円という今回のリソースは、このハイブリッドにちょうど噛み合う。

## 1. アカウント開設・初期設定（Week 0）

### 1-1. 種別とアカウント名
- **プロアカウント（クリエイター）に切替**（インサイト・広告に必須。設定→アカウントの種類）
- ユーザーネーム: 短く検索されやすいもの。例 `unmei_uranai` / `unmei.zukan`
- 表示名（プロフィールの名前欄）に**検索ワードを仕込む**: 例「運命図鑑ウンメイ｜MBTI×干支占い」
  （IGは“名前欄”も検索対象。占い・MBTI・相性などを入れる）

### 1-2. プロフィール（bio）
- 構成 = ①何ができるか1行 ②ベネフィット ③CTA＋リンク
- 例:
  ```
  生まれた日でわかる“運命キャラ”🐰✨
  MBTI×干支で無料診断／相性・全国ランキングも
  ▼ いま無料で占う
  ```
- **link in bio**: サイト直リンク、または `lit.link` / `Linktree` 等のリンク集で「診断・相性・ランキング」を並べる。**全リンクにUTMを付与**（§4）
- アイコン: 既存アセットの顔アップ（例 `rare_legendary_angelpoodle.png`）
- ハイライト: 「診断してみた」「レアキャラ」「相性」「使い方」の4つを整備

### 1-3. 連携・その他
- **Facebookページを作成 → Meta Business スイートに連携**（広告出稿に必要）
- 対象: 日本・13歳以上
- 開設時に**先に3〜9投稿を用意**して“ガラガラ感”を消してからフォロワー誘導を始める

## 2. ターゲット設計（ペルソナ）

メイン層 = **10代後半〜20代前半の女性中心**。「可愛い系 × 占い/診断 × シェア文化」の交差点。

| ペルソナ | 像 | 刺さる切り口 |
|---|---|---|
| A. 診断ジャンキー | MBTI好きの高校/大学生。心理テストをストーリーでシェア | 「MBTI別あるある」「◯◯型の運命」 |
| B. 恋愛・相性が気になる | 20代女性。気になる人・マッチング層 | 「相性は何点？」「◯◯型と相性がいいのは」 |
| C. 可愛いキャラ好き | サンリオ/ちいかわ的世界観が好き | ビジュアルで保存・シェアしたくなるキャラ |

**インサイト（欲求）:**
1. 自分のことを言い当ててほしい（自己理解・承認）
2. 結果を友達とシェアして盛り上がりたい（コミュニケーション）
3. 可愛いから保存・スクショしたい（ビジュアル）

→ クリエイティブの勝ち筋は **「結果をシェア・スクショしたくなる可愛さ」**。UNMEIの縦長シェア画像(1080×1920)とキャラ資産はこの点で強い。

## 3. コンテンツ設計（オーガニック運用）

### 3-1. フォーマット配分（週7・毎日投稿の前提）
- **リール 週4〜5** … 新規リーチの主力。ここに一番エネルギーを割く
- フィード（画像/カルーセル）週1〜2 … 保存狙い（早見表・あるある・ランキング表）
- **ストーリーズ 毎日1〜3** … リンクスタンプでサイト送客＋投票/質問で接触

### 3-2. ネタ切れしない「型」テンプレ
1. **MBTI別◯◯**（あるある / ランキング / セリフ）→ タグ付け・保存されやすい
2. **干支 × MBTI**（この掛け合わせがUNMEI独自）→ 「亥×INFPは…」
3. **レアキャラ紹介**（出現1%の射幸性。ガチャ動画的リール）
4. **相性ネタ**「◯◯型と△△型」→ コメントで自分の型を言わせて会話を作る
5. **全国ランキング煽り**「モテ全国1位のタイプは？」
6. **UGC/リアクション**「診断してみた」を募集・リポスト
7. **導線説明**（生年月日入れるだけ）月1回

### 3-3. 伸びるリールの作法
- 冒頭1秒で**フック**（「あなたの運命キャラ、当たってる？」）
- 大きい字幕＝**無音でも伝わる**。9:16フル画面
- **流行りの音源**を使う（発見面で有利）
- ラストに**CTA**「プロフィールのリンクから無料診断」＋「保存してね」
- 素材は既存のキャラPNG／縦長シェア画像を流用

### 3-4. 運用の回し方（毎日投稿を現実的に）
- 週1で**まとめ撮り＆予約投稿**（フィード/リールをストック）
- ストーリーズは当日ネタ（診断結果・投票）で軽く毎日
- ハッシュタグ: 大中小を混ぜて8〜15個
  例: `#MBTI #mbti診断 #占い #相性診断 #心理テスト #干支 #量産型 #かわいい #診断メーカー`
- 投稿時間: 放課後〜夜（17–22時）・土日を厚めに

## 4. サイト流入導線（収益ゴールの肝）

IG → サイトの3経路を**すべてUTM付き**で計測する:

| 経路 | 具体 | UTM例（`utm_content`） |
|---|---|---|
| link in bio | フィードで毎回「プロフィールのリンクから」と誘導 | `bio_link` |
| ストーリーズのリンクスタンプ | 診断結果・煽りから直リンク | `story_YYYYMMDD` |
| 有料広告 | フィード/リール/ストーリー広告 | `01hook_4x5` など |

- ベースUTM: `?utm_source=instagram&utm_medium=paid_social`（オーガニックは `utm_medium=social`）
- **計測は実装済み**: サイトに Meta ピクセル ＋ GA4 を設置済み（`index.html`）。ピクセルの実IDを入れれば広告最適化が回る（手順は `instagram-ad-plan.md` §1）
- サイト内イベント（診断完了=`result_view`→ViewContent、収益クリック=`monetize_click`→Lead）が自動でGA4/Metaへ飛ぶ実装済み

## 5. 有料広告（少額・月数万円）

- **目的**: まず**トラフィック**（リンククリック/LPビュー）。ピクセルに `ViewContent` が溜まったら**コンバージョン目的**へ切替
- **予算**: 月3万円＝1日約¥1,000。1〜2広告セットに集中（分散させない）
- **ターゲット**: 初期はAdvantage+/広め → データ後に**類似1%（ViewContentベース）**＋**リタゲ**（`quiz_start`済み未完了）
- **クリエイティブ**: 既存の**4コンセプト×3サイズ（作成済み `assets/ads/`）**を流用。まず 4:5 と 9:16
- 詳細な入稿手順・コピー案・キャンペーン構成・チェックリストは **[`instagram-ad-plan.md`](./instagram-ad-plan.md)**
- 相乗り効果: 広告で見つけた**勝ちクリエイティブをオーガニックのリールにも転用**

## 6. KPI と計測

**North Star = サイトのセッション/PV（＝収益の源泉）とその獲得単価。**

| レイヤー | 見る指標 |
|---|---|
| オーガニック | リール再生数 / 保存数 / プロフィールアクセス / リンククリック / フォロワー増 |
| 広告 | CTR（リンク）/ CPC / LPビュー / `ViewContent` 単価 |
| サイト | セッション / 診断完了率（`result_view`）/ シェア率 / RPM（広告収益÷セッション） |

**収益の逆算:**
```
目標月間PV  = 目標月間収益 ÷ 想定RPM(千PVあたり収益)
必要セッション = 目標PV ÷ 平均回遊ページ数
→ そこから 必要クリック数 / CTR / CPC / 投稿頻度 に分解
```
週次で GA4 ＋ IGインサイト ＋ Meta広告の3点を確認し、投稿・広告を調整。

## 8. 注意点（ポリシー・法務）

- **Metaの断定表現NG**: 「あなたは〜だ」と個人属性（性格・恋愛・メンタル・経済状況）を言い当てる表現は不可 → **問いかけ・提案形**にする（「あなたの◯◯がわかる」「診断してみよう」）
- **景表法**: 占い・診断で「必ず当たる」等の断定を避ける
- 対象年齢は**13歳以上**（Metaの最低ライン）
- 著作権: キャラ画像はDALL-E生成で自社所有（READMEに記載）。リールの**音源は商用利用可**のものを使う
